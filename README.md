# Video Downloader Server

Backend for the "حمّل فيديو" downloader website. It downloads videos from
YouTube, Facebook, TikTok, Instagram, X and any site yt-dlp supports, then
streams them back to the visitor as an mp4 file.

No API keys, no tokens, no accounts, nothing stored — each video is downloaded
to a temp file, streamed to the visitor, and deleted right after.

## Project layout

```
video-downloader/
├── server.js          The whole server (Express + yt-dlp)
├── package.json       express only; `npm start` runs the server
├── render.yaml        Render Blueprint — one-click deploy (free plan)
├── setup-guide-ar.md  Step-by-step Arabic deploy guide (phone-friendly)
└── package-lock.json  (generated by npm install; keep it for reproducible builds)
```

## Endpoints

| Method | Path | What it does |
|---|---|---|
| GET | `/` | Health check: `{ ok, service, activeJobs, maxJobs }` |
| GET | `/api/info?url=...` | Video title, duration, uploader, thumbnail, formats |
| POST | `/api/download` | Body `{ url, quality }` (quality: 360 / 480 / 720). Streams the mp4 back as a download. |

## Limits (abuse protection)

- Max 5 concurrent jobs (HTTP 429 when busy)
- Videos longer than 3 hours are refused
- Files bigger than ~500 MB are refused
- Only http/https URLs; localhost and private IPs are blocked
- If YouTube answers "Sign in to confirm you're not a bot" (datacenter-IP
  check), the server automatically retries once with the Android/iOS player
  clients, which usually get through

## Run it locally

```bash
npm install
# get the yt-dlp binary (Linux):
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o yt-dlp
chmod +x yt-dlp
node server.js
# then: curl "http://localhost:3000/api/info?url=https://youtu.be/oDTrTs_oiyQ"
```
